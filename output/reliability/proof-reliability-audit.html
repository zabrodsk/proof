What changed

  • Malformed probability distributions, unknown choices, and inconsistent winning choices are rejected. Effective confidence cannot exceed the selected choice's probability.
  • Support requires a strong verdict, a strong passage selection, and an aligned reason. A conflicting reason prevents positive clearance.
  • Evidence must come from the retrieved source text. A suggested quotation must occur in the displayed evidence passage.
  • Known correction, retraction, or update notices prevent positive clearance and carry through from search into later DOI-based checks during the server session.
  • Class reviews refresh source metadata. A failed refresh blocks the cited-page judgment.
  • PDF title matching requires the title text rather than a loose bag of words. File identity, completeness, and printed-page mapping remain manual checks.
  • A supported cited-page finding becomes uncertain if the wider article check does not confirm it.
  • Narrative citations match whole author tokens. Duplicate copies of a DOI do not count as different academic articles. PDF page indices must be unique and consecutive.

Real scholarly-source check

Retrieved the BMJ article Effect of exercise for depression through Crossref and Europe PMC, with 75 extracted body passages.

  • The published count of 218 studies was supported.
  • A deliberately incorrect count of 300 was marked as a number mismatch.
  • A universal claim about curing every adult remained uncertain.
  • The live scholarly search found six candidates and a correction notice. The affected article was marked uncertain until that notice is inspected.

The publisher's full PDF endpoint returned HTTP 403. The audit did not complete a live positive check of that publisher PDF. Existing real PDF fixtures passed parsing and page-boundary tests; fixtures are not a substitute for checking a student's actual PDF.

Deployed verification

The reliability update deployed successfully. A live check using a synthetic QA account returned a number mismatch for an incorrect claim, flagged an unrelated PDF as an identity issue, and returned HTTP 401 for an unauthenticated API request. The authenticated health check confirmed the Jev provider was configured.

Europe PMC was unavailable during the production PDF check. The app disclosed that only Crossref content was available. This production check does not establish that full-text retrieval is always available.

Limits that still matter

  • Models can be confidently wrong. Confidence thresholds and agreement checks reduce some failure modes but do not establish factual truth.
  • Selected passages can omit decisive context. PDF extraction can miss tables, figures, equations, scanned text, and reading order.
  • Search is not exhaustive. Corrections not returned by providers or not yet discovered may be missed. Known-notice memory is held for the current server session.
  • Peer-review status, study quality, full-PDF identity, printed page numbers, and class formatting still require inspection.
  • Language checks do not fact-check uncited claims against the world. Use source discovery and inspect the original evidence.

Reproducibility

The automated suite runs with npm test; the build runs with npm run build. The live matrix runs with PROOF_RELIABILITY_LIVE=true node --import tsx scripts/reliability-live.ts. It requires configured Jev credentials and consumes usage.

The response validator was checked against the official TypeSafe API schema. The app retrieves bibliographic records and selects evidence from source text; it does not ask the model to invent citations.

Reported Jev usage for the synthetic matrix and scholarly probes totaled approximately $0.00350. This is returned token usage, not an invoice, and excludes deployment checks.

No student drafts, account details, credentials, private URLs, or deployment identifiers are included in this public summary.
