What each mode does

Check citations

Audits supplied sources, repeated and narrative citations, exact locators, missing entries and bibliography formatting. Reference resolution needs explicit opt-in. This mode does not discover new sources.

Identity matches and evidence judgments appear separately. Bibliography-only documents can run an audit without inventing claims.

Generate citations

Reviews source-dependent facts and evidence-based interpretations, researches gaps and proposes citations with their exact supporting passages. Common knowledge receives no citation.

Selected changes add the matching Works Cited entries in one saved version. Unsupported claims remain visible as gaps after reopening.

Fact-check

All sources and Academic only route to different searches. Scientific claims keep their academic eligibility requirements in both scopes.

Private and literary claims need their original material. An exact passage is required before a claim can receive Supported status.

Names, headings, questions, instructions and preferences stay out of research. Uncertain claim candidates start selected for review. Selected evidence is assessed before additional discovery. Common knowledge stays available for fact-checking, but citation workflows do not search or cite an uncited exempt claim. Quotations, interpretations and specialist statistics still require attribution.

Approved edits create one immutable document version. Repeated requests return the same result. Stale drafts, changed evidence, overlapping edits and another owner's document cannot produce a partial save.

The shared citation formatter uses a pinned MLA style and an explicit classroom profile. Classroom assignment checks remain optional and separate. Classroom work receives an audit for manual changes in the required original document.

Only search results are reused across runs. Source text and publication status are refreshed, and each claim receives its own assessment.

  • Candidate resolution coalesces concurrent duplicate lookups. Unchanged source content can reuse an immutable snapshot; changed content creates a new one.
  • Complete permitted source sections are inspected, including later contradictions and uncertain passages.
  • Every retry and followed redirect reserves a real request. Concurrency is bounded, cancellation stops queued work and long cooldowns prevent premature retries.
  • Cross-origin redirects strip credentials and cannot forward a document or model request body through a 307 or 308 response.
  • Existing spending caps and evidence requirements remain in force. Exhausted budgets and inaccessible sources produce visible gaps.

What remains unverified

Production deployment has not been exercised. Live academic citation generation, Firecrawl recognition and hosted identity-provider login were not part of the live smoke run. Their applicable code paths have deterministic tests.

  • Automatic common-knowledge detection uses conservative stable-fact rules. Review can mark additional audience-specific facts. Quoted text, interpretations and specialist quantities cannot use that exemption.
  • The legacy standalone classroom import screen still requires DOI-based metadata verification. The general citation model can represent works without a DOI when their metadata establishes identity.
  • Original-document editing history, font and spacing require a manual check. Proof does not certify those requirements.
  • Plain text downloads cannot preserve italics or hanging indentation. Formatted HTML preserves citation emphasis and bibliography layout.
  • The build reports a 547 kB citation-formatting chunk. It is separate from the initial entry bundle. Further bundle tuning remains possible.
  • No live before/after cost or latency baseline was collected. The request reductions above come from repeatable provider fixtures.

A reviewer can inspect the proposed changes, run the documented tests and decide when to merge. Deployment needs its own live verification.
