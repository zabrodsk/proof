What changed

ProblemCurrent behavior
Uploaded sources bypassed citation correctness.Check citations inspects the cited work and page. The UI distinguishes a wrong citation page, wrong source, missing citation and unclear citation.
An older verified fix could apply after source eligibility changed.Single and batch fixes revalidate source status, frozen metadata, extraction and exact passage in the edit transaction. A changed or unavailable source blocks the edit. Incomplete extraction cannot produce an automatic fix.
A factual parenthetical inherited a common-knowledge exemption.Only recognizable author-and-locator citations are removed before checking for a familiar fact. Quantitative qualifications remain part of the assertion.
Middle sentences in quotations lost attribution requirements.Quote membership is checked against the original document span, including multiple sentences, paragraph breaks and contractions inside quotations.
Partial citation approval hid the remaining work.Saved plans record applied and deferred operations, retain explicit unresolved gaps, and store the actual saved preview. The remaining work stays visible after reopening.

What this does not establish

No new live provider smoke test was run in this follow-up. Live academic citation generation, OCR and hosted identity-provider login still need their own live acceptance run. The tests do not establish a production cost or latency improvement.

Common-knowledge detection remains deliberately narrow and reviewable. A familiar topic does not automatically exempt a quotation, interpretation or specialist claim. Plain-text exports cannot preserve typographic formatting; formatted HTML remains available.

The branch is ready for review of these changes. Merge and deployment remain separate steps.

Public report contains synthetic examples and public code references only.
