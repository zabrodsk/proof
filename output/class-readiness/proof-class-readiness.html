What works

  • Paste text, choose a claim, search journal articles, and inspect the passages used to judge support.
  • Import a read-only Google Doc snapshot or a document file. Keep the original school writing in the assigned Google Doc.
  • Use DOI metadata and uploaded full PDFs to prepare class-formatted MLA entries and inspect cited pages.
  • Review language, reasoning, assignment requirements, citation matching, cited-page evidence, and selected article context.
  • Separate browser sessions cannot read each other’s jobs. Incomplete checks remain visible and can be retried individually.

Cost for five people

Planning assumption: 20 reviews and 200 source searches per person each month. That means 100 short reviews and 1,000 searches in total.

  • Measured short language review: about $0.001 each, or $0.10/month.
  • Measured six-candidate source search: $0.00076–0.00091 each, or $0.76–0.91/month.
  • Combined measured Jev components: about $0.86–1.01/month. Cited-page checks, article length, retries, and unreturned requests can add cost.
  • Railway planning allowance: $5–15/month. Hobby has a $5 minimum credited toward usage; this is not a measured monthly bill.

Jev estimate uses $0.042 per million input tokens, with free output tokens. Usage shown is returned provider usage, not an invoice. Existing Railway plan usage can change the incremental charge.

Live checks and limits

  • Public health check succeeds. Protected API returns 401 before login. Authenticated API confirms Jev configuration.
  • Live source search retrieved six candidates, found supporting full text, and identified a correction notice rather than treating it as original research.
  • Build and all 74 automated tests passed. The five-session test also verifies ownership and retry recovery.
  • Exact printed-page mapping, peer-review status, methods, limitations, and publisher notices still need human inspection. A model judgment is not a guarantee of correctness.
  • Some publishers block automated PDF downloads. Upload the PDF obtained through school access in those cases. Full-PDF end-to-end live verification was not completed in this run.
  • Each review supports 100,000 characters, 1,000 sentences, eight papers, and up to 100 pages per paper. Five review jobs may run at once.
  • Drafts and reports are saved in the browser. Server jobs expire after one hour and do not survive a deployment restart.
